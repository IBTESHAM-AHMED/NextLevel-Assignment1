## Overview

This assignment is about TypeScript basics, function parameters, tuples, interfaces, type narrowing, generics, Promises, and OOP.

All 8 problems are solved in a single file, [solutions.ts](./solutions.ts):

1. `multiplyValue`: optional/default parameter
2. `processInput`: union type and `typeof` narrowing
3. `formatCoordinate`: readonly tuple
4. `concatenateArrays`: generics and rest parameters
5. `Course` / `getPopularCourses`: interface and array filtering
6. `pluckValues`: generics with `keyof`
7. `Employee` / `Manager`: classes, inheritance, `protected` and `private`
8. `validateAgeAsync`: Promises and `setTimeout`
